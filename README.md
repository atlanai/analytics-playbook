# IT Template Repo

Starter template for new Atlan internal IT / tooling repos. Click **"Use this template"** (top right) to create a new repo preloaded with:

- `CLAUDE.md` — Claude Code project instructions
- `AGENTS.md` — agent onboarding notes
- `.gitignore` — baseline ignores
- `.github/` — workflows and config scaffolding

After creating your new repo, replace this README with one describing what it actually does.
