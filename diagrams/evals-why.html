Is it right?Every answer is checked against a verified one, not against an impression.
Is it better than before?The same sealed questions, scored the same way, before and after each change.
What do we fix next?Each wrong answer points to a missing definition, one never served, or one ignored.
Is it safe to change?Rerun the set after every edit to a metric, rule or model, and see the break before users do.

Only a fixed test answers these. Without one, the agent is a demo.
