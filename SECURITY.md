# Security

If you find a security issue in this repository or on [analytics-playbook.atlan.com](https://analytics-playbook.atlan.com/), report it privately. Don't open a public issue.

Email [security@atlan.com](mailto:security@atlan.com). Atlan's [responsible disclosure program](https://atlan.com/responsible-disclosure-program/) covers how reports are handled and credited.

Include the page or file, what you found, and the steps to reproduce it.
